# Release 1.5.5.13

## Goal

Publish the merged correctness, performance and Alembic improvements as
duckdb-sqlalchemy 1.5.5.13, with verified PyPI and GitHub artifacts.

## Scope

Version metadata, changelog, publishing workflow and release documentation.

## Plan

- Prepare synchronized package/lock versions and migration-aware release notes.
- Validate the release PR, including workflow syntax, pre-commit, types and tests.
- Merge, wait for exact-commit checks, publish, verify hashes and installed behavior.

## Progress

- Prepared version 1.5.5.13 after checking that 1.5.5.12 was the latest release.
- Added publication triggered by a merged package version change.
- [Release PR #184](https://github.com/leonardovida/duckdb-sqlalchemy/pull/184)
  passed required checks and workflow validation, then merged.
- Published the exact merged commit
  `8289a232e89b78e0b138dc033fa0c5183b73ad8b`.
- Published and verified both distributions, then created the GitHub release.

## Surprises & Discoveries

The execution environment was unavailable and the GitHub connector could not
create releases directly. GitHub Actions provided builds, checks and the
existing trusted PyPI publisher. Pre-commit ran in CI rather than locally.

## Decision Log

- Preserved the existing version convention and PyPI publishing workflow identity.
- Required tests_passed, pre-commit and ty on the exact publishing commit.
- Verified public artifact hashes and a fresh wheel before creating the GitHub release.
- Confined release-token write permissions to the final release job.

## Validation

- [Release PR checks](https://github.com/leonardovida/duckdb-sqlalchemy/actions/runs/36764866576)
  passed Python 3.10–3.14, minimum dependencies, SQLAlchemy 2.0/2.1 upstream suites,
  Windows/macOS, six isolated wheel/sdist dependency combinations and benchmarks.
- [Lint and type checks](https://github.com/leonardovida/duckdb-sqlalchemy/actions/runs/36764866447)
  and [actionlint validation](https://github.com/leonardovida/duckdb-sqlalchemy/actions/runs/36764866516)
  passed before merge.
- [Merged-commit tests](https://github.com/leonardovida/duckdb-sqlalchemy/actions/runs/36765196108)
  and [lint/type checks](https://github.com/leonardovida/duckdb-sqlalchemy/actions/runs/36765195960)
  passed before publication.
- [Publishing workflow](https://github.com/leonardovida/duckdb-sqlalchemy/actions/runs/36765195970)
  passed build, strict twine validation, installed-wheel smoke, trusted PyPI
  publication, public wheel/sdist SHA-256 comparison and a fresh no-cache wheel
  installation with Arrow and pandas.
- The fresh install verified version 1.5.5.13 with DuckDB 1.5.6,
  SQLAlchemy 2.1.1, Arrow 25.0.1 and pandas 3.0.6.
- The GitHub release tag points to the exact publishing commit and includes both
  verified distributions.

Released [1.5.5.13 on PyPI](https://pypi.org/project/duckdb-sqlalchemy/1.5.5.13/)
and [GitHub](https://github.com/leonardovida/duckdb-sqlalchemy/releases/tag/v1.5.5.13).
