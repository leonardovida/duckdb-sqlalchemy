## Surprises & Discoveries

The execution environment is unavailable and the GitHub connector cannot
create releases directly. GitHub Actions provides builds, checks and the
existing trusted PyPI publisher. Pre-commit must run in CI rather than locally.

## Decision Log

- Preserve the existing version convention and PyPI publishing workflow identity.
- Require tests_passed, pre-commit and ty on the exact publishing commit.
- Verify public artifact hashes and a fresh wheel before creating the GitHub release.
- Keep release-token write permissions confined to the final release job.
